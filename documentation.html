How We Built the TV Boom Visualizations

A comprehensive walkthrough detailing the project's data narrative and the custom-engineered D3.js and Scrollama.js mechanics used to bring the numbers to life.

Project Summary & Story Flow

This project serves as a financial biography of modern English football. Below is the chronological sequence of the narrative, illustrating how the data story unfolds:

The Calm Before the Storm Pre-2013
The story opens in the Pre-TV Era. Premier League clubs operated under traditional budget constraints. Spending grew at a slow, predictable rate, and total league transfers hovered below £500M annually. Players were valuable, but prices remained tethered to traditional, self-sustaining club revenues.
The Financial Spark 2013
The tipping point: A record-breaking domestic television rights deal injects billions of pounds from broadcasters directly into Premier League club coffers. This sudden wave of cash instantly changes club budgets, causing an immediate, vertical spike in transfer market liquidity.
Mapping the Talent Influx Post-2013
Armed with deep pockets, English clubs scour the globe for the finest players. The project maps this Talent Influx geographically, visualizing the major trade corridors (primarily from France, Spain, Germany, Italy, and Brazil) that established England as the financial epicenter of world football.
Valuation Explosion 2013-2025
Hyper-inflation hits the transfer market. Because many rich clubs are chasing the same elite players, player prices skyrocket. The average player transfer fee increases by 190%, rising from £5.43M to £15.77M. Mid-tier signings suddenly command fees that would have broken records a decade prior.
Investment by Position 2013-2025
Where did all this cash go? The project concludes by analyzing Positional Investment. While forwards and attackers continue to demand premium fees, investment in defensive lines (defenders and goalkeepers) shows massive percentage gains, illustrating that inflation raised the value of entire squads.

1. Transfer Spending Line & Area Chart

Visually representing the transition from the pre-TV era (Chapter 1) to the post-TV era (Chapter 2) using a continuous timeline.

Pre- vs. Post-TV Spending Visual Chapters 1 & 2 • js/chapter4.js
Narrative & Visual Insight
This visualization traces Premier League spending over a 25-year period. The pre-TV era (2000–2012) is rendered in cyan, depicting a flat and stable trend line. As the user scrolls into the post-TV rights boom, an animated gold dot sweeps across the graph, drawing the post-2013 spending line and filling the area beneath it in translucent gold. This animation runs dynamically in both directions: scrolling downwards draws the surge, while scrolling upwards erases it, reinforcing the direct impact of the 2013 broadcasting deal.
Technical Implementation
The chart maps Pre-TV and Post-TV CSV datasets. To create a continuous path, the last data point of the Pre-TV array is prepended to the Post-TV array. We hide the Post-TV elements initially using an SVG <clipPath> mask.

As Scrollama registers scroll progress through Chapter 2, it triggers a custom transition tween. The width of the clip path rectangle increases dynamically based on the current horizontal coordinate of the path, while a tracer circle is positioned at the intersection point.
D3 Clipping & Tweening Implementation
// Set up the mask in SVG defs const clipRect = clipPath.append("rect") .attr("x", xScale(2012)) .attr("width", 0); // hidden initially // During scroll-linked count-up animation: t => { // Interpolate point coordinate along the post-TV path length const point = postPath.node().getPointAtLength(t * totalLength); runningDot.attr("cx", point.x).attr("cy", point.y); clipRect.attr("width", Math.max(0, point.x - xScale(2012))); }
Interactive Detail: Standard tooltips are integrated so users can hover over any individual season marker dot to inspect exact annual spending figures in millions/billions.

2. Global Transfer Flow Map

Visualizing the geographic movement and transfer volume of players moving into and out of England.

Talent Influx Map Visual Chapter 3 • js/chapter6.js
Narrative & Visual Insight
To represent the global reach of the Premier League's financial dominance, this visual maps the movement of players across countries. England is highlighted as the center of player movement, with active partner nations shaded in dark blue.

Curved paths flow between countries, with cyan lines indicating players bought by English clubs and gold lines representing players sold abroad. Animated particle dashes slide continuously along these paths, showing the direction of flow. Hovering over a country highlights its borders and dims unrelated paths, while tooltips list top players traded, transfer counts, and cumulative fees.
Technical Implementation
The map loads a custom GeoJSON world dataset and translates geographic coordinates into SVG space using a Mercator projection centered to emphasize Europe and the Americas.

Instead of drawing straight lines, we construct curved quadratic Bezier paths. By calculating the midpoint between England and a partner nation, we apply a perpendicular offset vector to bend the curve. To animate flows, we duplicate the path and apply a moving CSS dash-offset.
Bezier Curve and CSS Dash Animation
// Curved path data generator (SVG Quadratic Bezier) const pathData = `M ${source[0]},${source[1]} Q ${bendX},${bendY} ${target[0]},${target[1]}`; // CSS animation applied to the dashed flow overlay .flow-animation-line { stroke-linecap: round; stroke-dasharray: 6 15; animation: flow-dash 1.8s linear infinite; } @keyframes flow-dash { to { stroke-dashoffset: -42; } }
Zoom & Interaction: Users can pan and zoom using the mouse wheel or control buttons (implemented via d3.zoom()). Clicking a country automatically centers and zooms into its bounding box, while clicking the map background resets the view.

3. Valuation Explosion Indicator

Comparing average player valuations pre- and post-TV rights boom through a scroll-triggered counting card.

Average Fee Valuation Card Chapter 4 • js/chapter7.js
Narrative & Visual Insight
This component isolates player valuation inflation. It presents a large glassmorphic circular card centered in the viewport.

In the Pre-TV era, the card shows a calm cyan border and lists the average transfer fee at £5.43 Million. As the user scrolls down, the number rapidly counts up, stopping at £15.77 Million. Simultaneously, the border glow transitions from cyan to gold, and a gold subtitle fades in, reading "+190% Growth". Scrolling back up reverses the animation, counting the fee back down.
Technical Implementation
Rather than binding data to coordinates, this visualization interpolates raw numeric values. D3's transition engine parses the text values and counts up or down using the custom tween function.

The glow ring and text color are transitioned concurrently between the CSS variables --accent-cyan and --accent-gold.
D3 Numeric Interpolation
// Dynamically counting up numbers on scroll enter feeText.transition() .duration(1500) .ease(d3.easeQuadOut) .textTween(function() { const currentVal = parseFeeText(feeText.text()); // parse current text const interpolator = d3.interpolateNumber(currentVal, post); // interpolate to target return t => `£${(interpolator(t) / 1000000).toFixed(2)}M`; });
Interruptible Animations: All transitions are configured to allow interruptions. If a user scrolls quickly back and forth, the current animation stops and begins interpolating from its exact current state, preventing visual stutter.

4. Investment by Position

Analyzing which positions received the most cash injections using stacked horizontal bars.

Positional Spending Bar Chart Chapter 5 • js/chapter8.js
Narrative & Visual Insight
This final visual breaks down where the TV rights cash was spent by position (Forwards, Midfielders, Defenders, Goalkeepers).

It is presented as a stacked horizontal bar chart. The cyan bars represent the baseline Pre-TV spending. On scroll, gold bars grow outward from the end of the cyan segments, representing the Post-TV spending surge. A percentage growth indicator (e.g., +158% for defenders) fades in at the center of the gold segments, and the cumulative spending total label slides smoothly to the end of the bars.
Technical Implementation
This stacked bar layout utilizes a linear x-scale mapped to the combined sum of pre- and post-spending values.

The post-TV bar starts with an initial width of 0 and an x position of xScale(d.pre). During transition, we animate its width to xScale(d.post). The labels are animated to slide along with the growing bar to maintain coordinate alignment.
Coordinated SVG Transitions
// 1. Grow post bars width postBars.transition().duration(1500).attr("width", d => xScale(d.post)); // 2. Co-ordinate total label text and slide its x position totalLabels.transition().duration(1500) .attr("x", d => xScale(d.pre + d.post) + 8) .textTween(function(d) { const interpolator = d3.interpolateNumber(d.pre, d.pre + d.post); return t => formatLabelValue(interpolator(t)); });

Data Source & Methodology

Details regarding the data origins, source, and criteria used for the visualizations in this project.

Source Citation: All transfer market statistics, player values, and volume movements visualized in this project were retrieved from the Transfermarkt website.
To ensure analytical integrity and reflect the direct financial flow of the television rights boom, the following parameters were applied to the dataset:
  • Paid Transfers Only: The analysis includes exclusively transfer deals between clubs that involved a financial transfer fee.
  • Free Transfers Excluded: Free agent signings, player loan deals, and player swaps without monetary exchange are completely excluded. This ensures the data represents direct cash flows between clubs.
  • Currency Uniformity: All transfer values are computed and expressed in British Pounds Sterling (£).

Core Architecture & Libraries

How three simple front-end technologies are integrated to create a modern scrollytelling experience.

D3.js (v7)
Used for data binding, scaling, drawing vector SVGs, and animating geometric properties. It handles custom color transitions, number counts, and map projections.
Scrollama.js
A scroll-driven scrollytelling library. It monitors container steps as they enter the screen, triggering transitions. It also tracks exact scroll percentages (0.0 to 1.0) to sync animations with user scroll speed.
CSS Grid & Flexbox
Lays out the application. The charts remain locked in the center of the viewport via a sticky visual wrapper (position: sticky;), while the textual story cards scroll over them.
Design Theme: The project uses a glassmorphism aesthetic, featuring dark radial gradients, high-contrast typography (using the premium Google Font Outfit), and subtle translucent borders to make the layout feel polished.
